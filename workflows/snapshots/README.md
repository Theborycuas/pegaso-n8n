# Snapshots

Copias del workflow **tal como estaba en producción** antes de importar un cambio importante. Son el punto de retorno rápido si algo sale mal: se importan en n8n sin tener que reconstruir nada desde git.

El historial día a día ya lo guarda git en `workflows/pegaso-whatsapp.json`; aquí solo van los puntos de control.

Nombre: `pegaso-whatsapp_AAAA-MM-DD_<motivo>.json`, por ejemplo `pegaso-whatsapp_2026-10-07_antes-precios-v3.json`.
